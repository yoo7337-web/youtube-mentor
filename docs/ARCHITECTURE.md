# youtube-mentor 아키텍처 설계

> v0.4 — 2026-07-04. "터미널 Claude 인덱싱 + 정적웹 Gemini 상담"으로 단순화 확정.
> 벡터DB·임베딩·RAG·Streamlit 제거. **추가 API 비용 0원**(Gemini 무료 키 1개만 필요).

## 1. 목표

투자·경제 분야 유튜브 명사들의 발언을 학습해, 그 사람의 관점·근거로 사용자의
투자/경제 고민에 답하는 **개인 상담가**를 만든다. 핵심 가치:

1. **관점 재현** — 그 사람이라면 이 상황을 어떻게 볼까?
2. **근거 인용** — 답변이 어느 영상, 어느 발언에 기반했는지 출처를 항상 제시(환각 억제).
3. **인사이트 청취** — 고민 상담 + "지금 유망한 산업/종목/투자처"를 최신 발언 기준으로 듣는다.

## 1.5 설계 대원칙 (사용자 확정)

1. **지식 격리** — 전문가 1명 = 지식팩 1개. 검색·답변 생성 모두 전문가 단위로 격리.
   답변도 전문가별 별도 LLM 호출(서로의 답을 보지 못함). **절대 합치지 않는다.**
2. **개별 청취** — 여러 명에게 같은 질문을 던져도 답변은 각각 카드로 표시. 합성·통합 결론 없음.
3. **시점 명시** — 모든 인사이트·인용에 영상 날짜 부착. 답변에 "2026년 6월 영상 기준" 식으로 표기.
   "유망" 질문은 최신 발언 우선.

## 2. 전체 아키텍처

**API 키 필요: Gemini 무료 키 1개뿐.** Claude는 Claude Code 구독 세션이 직접 처리(별도 API 불필요).

```
[인덱싱 — Claude Code 터미널, 수동 트리거, 구독으로 처리]
  ⭐"멘토 인덱싱해줘" (전체 또는 특정 전문가)
   → 스크립트: 새 영상 자막 수집 (youtube-transcript-api, 무료)
   → Claude(세션 내)가 직접 인사이트 추출·정리 (별도 API 호출 아님)
   → 전문가별 "지식팩" JSON 생성/증분 갱신
        · 인사이트 테이블 {topic, tickers, direction, thesis, date, video}
        · 핵심 발언 인용(quotes) + 영상링크/타임스탬프
        · 페르소나 말투·가드레일 요약(persona)

[질문 창구 2개 — 같은 지식팩을 공유]
  A. 정적웹 사이트 (GitHub Pages 배포, 폰에서도 접속)
     전문가 선택 + 질문
       → 선택한 전문가별 지식팩을 통째로 Gemini(무료 API) 컨텍스트에 투입
       → 전문가별 개별 호출 → 답변 카드 나란히 (합성 없음) + 출처
     Gemini 키: 브라우저에 1회 입력 → localStorage 저장 (코드/repo에 미포함)

  B. Claude Code 터미널 (고품질 상담)
     ⭐"○○○에게 물어봐줘" → Claude가 지식팩 로드해 페르소나로 답변 (구독, API 불필요)
```

### 왜 벡터DB/RAG가 없는가
지식팩을 **통째로** LLM 컨텍스트에 투입하는 방식(대용량 컨텍스트 활용)이므로 유사도 검색
레이어가 불필요. 개인 규모(전문가 14명)에서 지식팩 1개는 컨텍스트에 충분히 들어간다.
"고민 상담"과 "유망 산업/종목"을 모두 같은 지식팩(비정형 인용 + 정형 인사이트 테이블)으로 커버.

### 사이트 UI 요구사항 (정적웹)
- 전문가 선택 + 질문 → 답변 카드 나란히(합성 없음) + 근거 출처(영상·날짜·타임스탬프).
- **인덱싱된 영상 목록(필수, 사용자 요청)**: 각 전문가 카드/패널에 인덱싱에 사용된
  **유튜브 영상 링크 전체**를 표시(제목+날짜+링크). 지식팩 `videos[]`를 그대로 렌더한다.
  → 어떤 영상이 학습됐는지 사용자가 직접 확인 가능(투명성).

### 지식팩 스키마 (`data/knowledge-packs/<slug>.json`)

```jsonc
{
  "slug": "kimdante",
  "name": "김단테",
  "persona": { "domain": "...", "tone": "...", "guardrails": "..." },
  "last_indexed": "2026-07-04",
  "videos": [ { "id": "...", "title": "...", "date": "2026-06-12", "url": "..." } ],
  "insights": [
    {
      "topic": "반도체",          // 주제 정규화 태그 (타임라인·대립보드 축)
      "tickers": ["005930"],       // 종목코드 (보유종목 매칭·스코어카드 축)
      "direction": "긍정",         // 긍정 | 부정 | 중립
      "thesis": "...(논거 요약)",
      "date": "2026-06-12",        // 발언 영상 날짜 (시점 명시)
      "video": "...(영상URL#t=750)"
    }
  ],
  "quotes": [ { "text": "...", "date": "...", "video": "...#t=..." } ]
}
```
> `topic`/`tickers`는 로드맵 기능(뷰 타임라인·의견 대립 보드·보유종목 매칭·적중률 스코어카드)의
> 공통 기반이므로 v1.0 인덱싱부터 채운다.

'의견 대립 보드'(각자 발언을 나란히 놓기만)가 대체. TTS·실시간 시세는 과잉으로 제외.

## 4. 기술 스택 (확정)

- **자막 수집**: `youtube-transcript-api` (자동자막 우선, 한/영). 없으면 스킵(추후 Whisper 옵션)
- **인덱싱·인사이트 추출**: Claude Code 세션이 직접 수행 (구독, 별도 API 없음)
- **터미널 상담**: Claude Code 세션 (지식팩 로드 → 페르소나 답변)
- **웹 상담**: 정적웹(HTML/JS) + **Gemini 무료 API** (브라우저에서 직접 호출)
- **배포**: GitHub Pages (정적). 로컬 미리보기 포트 8509
- **저장**: `data/knowledge-packs/*.json` (git 커밋 — 사이트가 읽음) / 원본 자막은 git 제외
