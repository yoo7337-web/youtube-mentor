# youtube-mentor

> 유튜브 투자·경제 전문가(명사)들의 영상을 분석해, 그들의 관점·지식·말투를 학습한 **개인 AI 상담가**로 만드는 프로젝트.
> 예) 특정 투자 구루의 유튜브를 학습시켜 "내 포트폴리오, 이 사람이라면 어떻게 볼까?"를 근거와 함께 답변받기.

**상태:** 설계 v0.4 (폴더+설계문서+페르소나 12명 완료, 코드 미착수)
**핵심:** 인덱싱은 Claude Code 터미널(구독)이, 질문은 정적웹(Gemini 무료) 또는 터미널이 처리 → **추가 API 비용 0원**
**포트:** 8509 (정적웹 로컬 미리보기)

---

## 핵심 아이디어

한 명의 전문가 = 하나의 **페르소나** = 하나의 **독립 지식팩**(절대 합치지 않음).
자막을 수집해 Claude가 인사이트로 정리한 지식팩을 만들고, 질문하면 각 전문가가
**자기 근거만으로 따로따로** 답한다.

```
[인덱싱 — Claude Code 터미널, ⭐"멘토 인덱싱해줘", 구독으로 처리]
   유튜브 자막 수집(무료) → Claude가 인사이트 추출
   → 전문가별 지식팩 JSON  { 인사이트[topic/tickers/방향/논거/날짜] + 인용 + 영상링크 }

[질문 — 지식팩 공유]
   A. 정적웹(GitHub Pages, 폰 접속): 전문가 선택+질문 → 지식팩 통째 → Gemini 무료 → 답변 카드 나란히
   B. 터미널: ⭐"○○○에게 물어봐줘" → Claude가 지식팩 로드 → 페르소나 답변 (API 불필요)
      → 여러 명이면 답변 각각 표시 (합성·요약 없음) + 출처(영상·타임스탬프·날짜)
```

벡터DB·임베딩·RAG 없음 — 지식팩을 통째로 LLM 컨텍스트에 넣는 방식. 필요한 외부 키는 **Gemini 무료 1개뿐**.

## 전문가 로스터 (파일럿 12명)

**1차 웨이브(검증)**: 김단테 · 슈카 · 레이 달리오
**2차**: 오건영 · 홍춘욱 · 박세익 · 임형록 · 소수몽키 · 워런 버핏 · 하워드 막스 · 캐시 우드 · 피터 린치
> 상세·채널ID는 `personas/*.yaml`, `docs/ARCHITECTURE.md` §5.

## 기능 로드맵 (전부 v1 범위)

- **v1.0** 지식팩 인덱싱 + 패널 상담(코어)
- **v1.1** 뷰 타임라인(견해 변화 추적) · 의견 대립 보드(12명 입장 비교)
- **v1.2** 보유종목 매칭(stock-radar 재활용) · 텔레그램 알림(@dsrkrbot)
- **v1.3** 상담 일지 · 적중률 스코어카드(인사이트 vs 실제 주가)

## 프로젝트 구조

```
youtube-mentor/
├─ README.md / CLAUDE.md
├─ docs/ARCHITECTURE.md      # 상세 설계·의사결정
├─ personas/*.yaml           # 전문가 정의(채널·말투·가드레일·intro)
├─ data/
│   ├─ knowledge-packs/      # 전문가별 지식팩 JSON (git 커밋 — 사이트가 읽음)
│   ├─ transcripts/          # 원본 자막 (git 제외)
│   └─ consultations/        # 상담 일지 (v1.3)
├─ src/                      # 수집·인덱싱·사이트 코드 (미구현)
└─ requirements.txt
```
